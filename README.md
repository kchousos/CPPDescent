# CPP-Descent

Part of the [“Software Development for Computing Systems”
course](https://eclass.uoa.gr/courses/DI485/) of the [Department of
Informatics and Telecommunications, UoA](https://www.di.uoa.gr/en) for
the first semester of the academic year 2023-2024.

This project constitutes an implementation of the KNN-Graph creation and
search algorithms described in \[1\], \[2\].

## Code Structure

In the [wiki](https://kchousos.github.io/CPPDescent/), you can find
documentation generated by [Doxygen](https://www.doxygen.nl/).
